- [Полный код](lab2_cross_validation.py) в стиле основной ЛР2: последовательные блоки, две небольшие функции, словарь архитектур и обычные циклы.
- [Вывод по результатам запуска](results/conclusion.md).
- [Интерпретация качества, влияния параметров и кривых обучения](results/analysis.md).
- [Зависимости](req.txt), [полный список версий](requirements-lock.txt).

Используется **тот же датасет Rice (Cammeo and Osmancik)**, что и в `lab2`. В отдельной папке `data` сохранены точные копии CSV, исходного ARFF, условий цитирования и сведений об источнике. Доступ к интернету для расчётов не нужен. Основная лабораторная не изменяется.

В сохранённом запуске победила исходная конфигурация: CV accuracy **93.04% ± 1.12 п.п.** (std). Test accuracy baseline и финальной сети одинакова — **91.73%**. Перебор подтвердил базовые настройки; прирост на test равен нулю.

## Что выполнено

1. Первичный анализ: типы, пропуски, дубликаты, распределения классов и признаков.
2. Baseline TensorFlow: один скрытый слой из 16 нейронов, ReLU, Adam(lr=0.001), 40 эпох, batch=32.
3. Пятикратная стратифицированная CV с одинаковыми фолдами для всех конфигураций.
4. Полный Grid Search: три learning rate × три архитектуры, 9 конфигураций и **45 обучений**.
5. TensorBoard: train/validation accuracy и loss для каждого фолда; CSV с историей каждой эпохи.
6. Сравнение accuracy, loss, времени fit, разброса по фолдам и разрыва train/validation. Кривые всех конфигураций и тепловая карта влияния параметров.
7. Обучение победителя на полном train и сравнение с baseline на одном test; матрицы ошибок и итоговые выводы.

## Методика

Данные содержат 3810 объектов и семь числовых признаков. Цель: Osmancik=0, Cammeo=1. Пропусков и полных дубликатов нет. Соотношение классов — 57.22% / 42.78%; применяется стратификация, дополнительные веса классов не используются.

| Набор | Объектов | Назначение |
| :--- | ---: | :--- |
| Train | 3048 (80%) | Baseline, Grid Search и финальное обучение |
| Test | 762 (20%) | Сравнение baseline и выбранной сети |
| Validation одного фолда | 609–610 | Оценка конфигурации внутри CV |

Тестовое разбиение с seed=42 совпадает с основной ЛР2. Здесь оставшиеся 80% целиком используются для CV: отдельная validation основной работы больше не нужна. Поэтому результаты следует сравнивать с **baseline этого дополнительного задания**, обученным на тех же 80%, а не напрямую с сетями основной работы, обученными на 60%.

Внутри каждого фолда `StandardScaler` обучается заново только на его обучающей части. Для baseline и финальной сети общий scaler обучен на полном train. Test не участвует в масштабировании, fit, выборе архитектуры, lr, числа эпох или порога.

| Архитектура | Скрытые слои | Dropout | Параметров |
| :--- | :--- | :--- | ---: |
| dense16 | 16 | нет | 145 |
| dense32_16 | 32 → 16 | нет | 801 |
| dropout32_16 | 32 → 16 | 0.25 после каждого скрытого слоя | 801 |

Learning rate: **0.0001, 0.001, 0.01**. Везде Adam, ReLU, выход sigmoid, binary cross-entropy, 40 эпох и batch=32. Порог класса 1 равен 0.5. EarlyStopping нет: сравниваются веса последней эпохи. Всего 47 обучений: baseline, 45 CV-фолдов и финальная модель.

Победитель выбирается по максимальной **средней CV accuracy**; при точном равенстве — по меньшему std, loss, числу параметров и имени. Std считается с `ddof=1`. Время измеряет fit с validation и TensorBoard, без предобработки и прогнозов; оно зависит от компьютера и не является критерием выбора. Указанный std — разброс пяти результатов, не доверительный интервал.

## Запуск

Можно использовать уже установленное окружение ЛР2. Из корня проекта:

```bash
lab2/.venv/bin/python lab2_extra/run_notebook.py
```

Скрипт синхронизирует кодовые ячейки с `.py`, выполняет ноутбук в чистом ядре и сохраняет выводы. Расчёт на CPU может занять несколько минут. Если выполнять только листинг:

```bash
MPLBACKEND=Agg lab2/.venv/bin/python lab2_extra/lab2_cross_validation.py
```

В VS Code или Jupyter откройте ноутбук, выберите ядро `lab2/.venv` и выполните **Restart Kernel and Run All Cells**. Код работает при рабочей папке в корне проекта или в `lab2_extra`.

Для самостоятельного окружения на Python 3.12:

```bash
python3 -m venv lab2_extra/.venv
lab2_extra/.venv/bin/python -m pip install -r lab2_extra/req.txt
lab2_extra/.venv/bin/python lab2_extra/run_notebook.py
```

В Windows / PowerShell с существующим окружением:

```powershell
.\lab2\.venv\Scripts\python.exe lab2_extra\run_notebook.py
```

Для нового окружения используйте `python -m venv lab2_extra/.venv`, затем `.\lab2_extra\.venv\Scripts\python.exe -m pip install -r lab2_extra/req.txt`. Для ноутбука потребуется выбрать это ядро.

## TensorBoard

```bash
lab2/.venv/bin/tensorboard --logdir lab2_extra/logs/tensorboard --port 6006
```

В PowerShell:

```powershell
.\lab2\.venv\Scripts\tensorboard.exe --logdir lab2_extra/logs/tensorboard --port 6006
```

Откройте **http://localhost:6006**. В Time Series / Scalars выберите теги `epoch_accuracy` и `epoch_loss`. Для каждой конфигурации и `fold_1`…`fold_5` доступны подкаталоги `train` и `validation`. Получаются четыре кривые: accuracy/loss на обучении и валидации. У baseline и финального обучения есть только train: test в callback не передаётся.

Каждое выполнение создаёт свою группу событий. Точный путь текущего запуска записан в [results/run_info.json](results/run_info.json). При сравнении выбирайте одну группу. Готовые PNG показывают кривые всех конфигураций без запуска TensorBoard.

## Результаты и проверка

- [cv_folds.csv](results/cv_folds.csv) — все 45 оценок, размеры выборок и время обучения.
- [cv_results.csv](results/cv_results.csv) — девять конфигураций, средние и std, итоговый рейтинг.
- [parameter_effects.csv](results/parameter_effects.csv) — усреднённое влияние lr и архитектуры.
- [test_metrics.csv](results/test_metrics.csv) — baseline и лучшая сеть на test.
- [test_predictions.csv](results/test_predictions.csv) — вероятности и прогнозы тестовых объектов.
- [oof_predictions.csv](results/oof_predictions.csv) — вероятности каждого обучающего объекта в его validation-фолде для всех конфигураций.
- [split_assignment.csv](results/split_assignment.csv) — train/test и номера CV-фолдов.
- [histories](results/histories) — истории обучения; [plots](results/plots) — графики.
- `results/models` — локально сохранённые baseline, лучшая сеть и scaler; модели исключены из Git и создаются повторным запуском.

Проверка сохранённых результатов без нового обучения:

```bash
lab2/.venv/bin/python lab2_extra/verify_results.py
```

Проверяются разделение данных, полнота сетки, метрики по сохранённым прогнозам, средние и std, выбор победителя, наличие 40 эпох в TensorBoard и выполнение всех ячеек ноутбука. Если модели сохранены локально, проверяются и их прогнозы.

При изменении сетки, числа эпох или данных заново выполните весь ноутбук. Численный вывод в последней кодовой ячейке и `results/conclusion.md` обновляется автоматически. Раздел «Интерпретация сохранённого запуска», `results/analysis.md` и краткий результат в этом README нужно обновить вручную.
